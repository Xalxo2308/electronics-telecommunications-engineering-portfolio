# Embedded Programming

This folder contains embedded-programming evidence from the project.

## Microcontroller

ATmega168 AVR microcontroller

## Documented Functions

- GPIO control
- Motor control
- LCD control
- Touchscreen input
- Sensor input
- Conditional logic
- Loops
- Timing and delays
- Parking and unparking control

The project documentation contains embedded C-style microcontroller control code.
