# Components

This folder contains component specifications and component-selection evidence from the project.

## Major Components

- ATmega168
- L293D motor driver
- Resistive touchscreen
- 12 V DC motors
- 16×2 LCD
- 16 MHz crystal oscillator
- 7805 voltage regulator
- Resistors
- Capacitors
- Diodes

The supporting documentation provides component specifications and their roles within the system.
