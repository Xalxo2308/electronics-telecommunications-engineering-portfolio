# Projects

## 1. Touch Screen Controlled Wheelchair

A Bachelor of Technology project developed in Electronics and Communication Engineering.

The project investigated a microcontroller-based wheelchair controlled through a resistive touchscreen interface.

### Main system components

- ATmega168 microcontroller
- Resistive touchscreen
- L293D motor driver
- Two brushed DC motors
- 16×2 LCD
- 16 MHz crystal oscillator
- Voltage regulators
- Resistors and capacitors
- Supporting electronic components

### System architecture

The touchscreen provides user input to the ATmega168 microcontroller.

The microcontroller processes the touchscreen input and generates control signals for the L293D motor driver. The motor driver interfaces with the DC motors to control wheelchair movement.

The LCD provides user-facing status information.

### Engineering work documented

- Microcontroller architecture and pin mapping
- Circuit design
- Touchscreen interfacing
- ADC-based input processing
- Motor-driver interfacing
- DC motor direction control
- LCD interfacing
- Embedded programming
- PCB layout design
- PCB fabrication
- Component specification
- Engineering documentation
